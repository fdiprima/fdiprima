### 📊 Progetto in evidenza

**[L'uso dell'intelligenza artificiale per lo studio della povertà: analisi del risparmio](https://github.com/fdiprima/tesi-poverta-istat)**

Tesi di laurea magistrale in Statistica multivariata e data mining (a.a. 2025-2026).

- Microdati Istat sull'Indagine sulle spese delle famiglie 2024: **28.054 famiglie, 1.627 variabili**
- Costruzione di un dataset di 57 predittori senza *data leakage* (quote di spesa COICOP, caratteristiche della famiglia e dell'abitazione)
- Confronto tra **regressione logistica, SVM, rete neurale, random forest e XGBoost** per prevedere la povertà relativa
- Gestione delle classi sbilanciate (resampling), divisione training/validation/test, tuning dei parametri, test di DeLong e McNemar
- Codice interamente in **R**, riproducibile
